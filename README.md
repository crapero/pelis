# 🎬 En la tele: las mejores películas de hoy en Argentina

¿Qué película buena dan hoy en el cable? Esta página junta la programación
de más de 50 canales de Argentina (TNT, Space, Cinecanal, AMC, Star Channel,
TCM, Warner y más), le pone el puntaje de cada película y te arma una
**rutina para ver la mayor cantidad de pelis buenas sin que se superpongan**.

👉 **[Ver la programación de hoy]([https://porreo.github.io/pelis/]())**

## Qué tiene
- Películas de hoy y de los próximos 7 días, ordenadas por puntaje u horario
- Rutina sin superposiciones con alternativas a cada hora
- Series, deportes, noticias, canales de aire y documentales
- Indicador de lo que está EN VIVO ahora
- Pensada para el celular

## Cómo funciona
Un script en Python (`mejores_pelis.py`) se ejecuta automáticamente todos
los días con GitHub Actions y regenera la página.

## Fuentes
- Horarios: [mi.tv](https://mi.tv/ar)
- Puntajes, imágenes y sinopsis: IMDb (vía mi.tv) y [TMDB](https://www.themoviedb.org).
  Este producto usa la API de TMDB pero no está avalado ni certificado por TMDB.
